## 二、配色体系

整站以「墨蓝 + 米白 + 铜金」为基调，状态色只用于状态标签。

| 角色 | 令牌 | 色值 | 用途 |
|------|------|------|------|
| 主色 | `--color-primary` | `#1F3A5F` | 品牌、主按钮、选中菜单、链接 |
| 主色深 | `--color-primary-deep` | `#16283F` | 登录页品牌区、侧边栏底色 |
| 中性底色 | `--color-paper` | `#F6F2EA` | 内容区背景 |
| 中性面 | `--color-surface` | `#FFFFFF` | 卡片、表格、弹窗 |
| 文字 | `--color-text` | `#22262B` | 正文 |
| 次要文字 | `--color-text-muted` | `#6B7280` | 说明、表头 |
| 强调色 | `--color-accent` | `#B4894A` | 少量装饰线、标题强调 |
| 成功 | `--color-success` | `#3F8F5B` | 仅状态标签 |
| 警告 | `--color-warning` | `#C58B2A` | 仅状态标签 |
| 危险 | `--color-danger` | `#C24A4A` | 仅状态标签、危险按钮 |

- 圆角：卡片 10px，按钮 6px，输入框 6px。
- 阴影：卡片使用极浅的暖灰阴影，不使用大面积发光。
- 字体：标题使用系统衬线字体（`Noto Serif SC`, `Songti SC`, serif）营造馆藏气质；正文使用系统无衬线字体。

## 三、布局与栅格

- 登录页：左右分栏，左侧 56% 品牌区，右侧 44% 登录卡；窄屏（< 900px）隐藏品牌区，登录卡居中。
- 主布局：顶部栏 64px + 左侧菜单 224px（可折叠至 64px）+ 内容区自适应。
- 内容区：最大宽度 1440px，左右留白 24px；列表页统一「页头 → 搜索筛选卡 → 表格卡 → 分页」。

## 五、交互反馈统一约定

| 场景 | 约定 |
|------|------|
| 查询/提交 | 按钮 loading，期间禁止重复点击 |
| 成功 | `ElMessage.success` 顶部提示 |
| 失败 | 展示后端 `message`；401 清登录态回登录页；403 提示无权限 |
| 危险操作 | `ElMessageBox.confirm` 二次确认 |
| 空数据 | 表格 empty-text 使用业务化文案 |
| 加载中 | 表格 `v-loading`，骨架不闪烁 |
